# Анализ тематики и конкурентов zelmedservice.ru

## Тематика

ООО «ЗелМедСервис» (Москва, Зеленоград, технопарк «ЭЛМА») поставляет медицинское оборудование экспертного класса для лечебных учреждений (ЛПУ). Клиенты — главные врачи, заведующие отделениями и закупщики по 44-ФЗ / 223-ФЗ. Цены на сайте не публикуются («по запросу»).

Направления каталога:

- **Лучевая диагностика** — КТ, МРТ, ПЭТ/КТ, ангиографы, маммографы, флюорографы, палатные рентгены, С-дуги, аппараты на 2 рабочих места, телеуправляемые аппараты
- **Ультразвуковая диагностика** — Samsung, Canon Aplio, Alpinion
- **Эндоскопия** — Fujifilm, Concemed, ЭФА-М
- **Стоматология** — Cingol

Проблемы текущего сайта: длинная лента ~50 позиций без фильтров, слабая мобильная версия, нет QR-кодов и печатных материалов для выставок.

## 10 конкурентов из поисковой выдачи

### 1. urusmed.ru
Официальный дистрибьютор Canon. Шапка в два ряда: телефон, рассрочка / лизинг / гарантия, «Скачать каталог»; ниже мегаменю на 20+ направлений. Цвета: синий `#2a77ed` на светло-сером.

### 2. spectrummed.ru
Мегаменю «направление → тип → бренд» (страна, класс, популярные бренды). В шапке «Пригласить на конкурс» и «Оставить запрос». В карточке: цена, наличие, гарантия, страна.

### 3. medliga.ru
Горизонтальное меню (Производители, Акции, Сервис, Госзакупки) + выпадающий «Каталог товаров» с фильтром «В наличии». Переключатель валюты.

### 4. global-mt.ru
Битрикс. Над шапкой служебные ссылки; рядом с поиском «Все категории». На главной блок каталога. Фирменный цвет — изумрудный `#088269`.

### 5. mrigroup.ru (ГК «Резонанс»)
Лендинг «оснащение под ключ»: плитки каталога, «Что вы получаете», карта поставок, FAQ, форма консультации.

### 6. md-system.ru
Tilda, без поиска. Крупный hero с цифрами («150+ поставщиков», «1–3 дня») и карточки направлений с числом моделей.

### 7. permedcom.ru (ПМК)
Двухуровневая шапка + «Каталог оборудования» с мегаменю. На главной партнёры, кейсы, география, новости. Бирюза `#2dafe5` / `#4bbecf`.

### 8. medsyst.ru
Каталог в стиле интернет-магазина: избранное, сравнение, корзина, город, языки. Блоки производителей, популярной техники, демозалов.

### 9. medison.ru
Дистрибьютор Samsung. Простой сайт с быстрой навигацией по моделям списком.

### 10. volgamedcomp.ru
В шапке быстрые ссылки МРТ / КТ / УЗИ и выпадающие списки моделей. Слайдер флагманов, метки NEW / ECO.

## Выводы для редизайна

| Элемент | Паттерн отрасли | Наше решение |
|---|---|---|
| Шапка | 2 ряда: контакты + лого / каталог / поиск / КП | То же + мобильная нижняя панель |
| Каталог | направление → тип → бренд, чипы, плитки с счётчиками | JSON-каталог + фильтры |
| Главная | hero → направления → флагманы → бренды → преимущества → форма | Тот же порядок |
| Отличие | — | QR на страницах + печатная табличка для стенда |
| Не берём | Корзина, сравнение, валюты | B2B без онлайн-оплаты |
