# Печатная брошюра товара (для будущего каталога)

На карточке и странице товара нужна кнопка:

**«Брошюра для стенда»**

Альтернативы (если захотите другой тон):

- «Печать для выставки»
- «Табличка на стенд»

## Что делает кнопка

Открывает `/stand/[slug]/` (или `?print=1`) — одностраничную A4-брошюру:

1. Логотип ЗелМедСервис
2. Название и бренд товара
3. Крупное фото
4. 3–5 ключевых характеристик
5. **Крупный QR-код** со ссылкой на страницу товара на сайте
6. Телефон и email

Стили `@media print` — без шапки/футера сайта. На экране — кнопки «Распечатать» и «Скачать QR».

Каталог и данные обсуждаются отдельно; этот документ фиксирует только UX-решение.
