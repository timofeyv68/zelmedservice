# Рекомендации по сайту ЗелМедСервис

Цели: презентация каталога на выставках, поиск модели на ПК/телефоне, SEO по запросам «купить [тип оборудования] / [бренд] для ЛПУ».

## Что уже сделано в этой итерации

- Каталог только из PDF 2026 (63 позиции), без данных старого `/catalog/`
- SEO-структура: `/catalog/`, `/catalog/[category]/`, `/catalog/[category]/[slug]/`, `/brands/[slug]/`
- Фильтры: поиск, направление, категория, бренд
- QR + кнопка **«Брошюра для стенда»**
- Страницы: о компании (инфографика-статы/этапы), новости без картинок, бренды, контакты
- Шапка: иконка логотипа + текст «ЗЕЛМЕДСЕРВИС», на мобиле только иконка

## Что добавить дальше

1. **Фото товаров** из PDF/съёмки — сейчас у большинства плейсхолдер бренда.
2. **Характеристики** (срезы КТ, Тесла МРТ, класс УЗИ) — сильный SEO и фильтры «16/64/128 срезов».
3. **Подкатегории рентгена**: палатные / телеуправляемые / 2 рабочих места / флюорографы (сейчас одна «Рентгенодиагностика»).
4. **Отдельная категория ПЭТ/КТ** (ScintCare 730T сейчас в КТ по оглавлению PDF).
5. **Форма заявки** через Formspree/Bitrix24 вместо mailto.
6. **Sitemap.xml + robots.txt + Schema.org** Product / Organization / BreadcrumbList.
7. **Страницы под коммерческие запросы**: «компьютерный томограф купить», «УЗИ аппарат Samsung купить» (частично закрыто брендами/категориями).
8. **Блок кейсов/поставленных объектов** для доверия в B2B.
9. **Лицензии/сертификаты** отдельной страницей со скачиванием.
10. **Яндекс.Метрика / цели** на «Запросить КП» и «Брошюра для стенда».

## Что изменить

1. Убрать дубли в PDF-оглавлении (Canon Aplio flex / go отдельно и вместе) — после сверки с менеджером.
2. На старом сайте в «Бренды» много марок без товаров в PDF 2026 — не тащить пустые SEO-страницы.
3. Новости: переписать slug’и человекочитаемо и почистить HTML-сущности в текстах.
4. PDF в шапке сейчас ведёт на `/catalog-2026.pdf` в `public/` — следить за актуальной версией файла.
5. Пункт 4 в ТЗ оборвался на «Создай» — нужно уточнение, что именно создавать дальше.
